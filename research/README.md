# Research Workspace

This directory is reserved for research briefs and their supporting evidence.

```text
research/
├── briefs/     scoped questions, assignments, and result handoffs
└── evidence/   source material and provenance supporting those results
```

The storage format and evidence contract are not frozen. Do not add credentials, cookies, personal session data, or material that cannot be published safely.

Use the skeleton in [RESEARCH-METHOD.md](../RESEARCH-METHOD.md) when preparing the first real brief.
