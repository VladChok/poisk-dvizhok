# Legend

**Status:** bootstrap

This file will hold the shared vocabulary used by Research and News agents when real work shows that a term needs a stable meaning.

No dictionary is defined during bootstrap. Terms should be added only when they help agents locate context, distinguish concepts, or hand work to one another without ambiguity.

Each future entry should point to the evidence or reviewed decision that established it. The Legend should explain shared language; it should not become a second source of truth for research findings.
