# Source Harness

This directory is reserved for shared source-access mechanisms used by replaceable Research and News agents.

```text
harness/
├── sources/   future source or platform access mechanisms
└── skills/    future agent-facing source access instructions
```

The Source Harness is one part of the Research Engine. It does not define the research method, prove claims, preserve all memory, or make product decisions.

No adapters, upstream code, credentials, cookies, or session data are included during bootstrap. The structure may change after the Agent Reach source review.
